왜 지갑 안에 들어가야 하나

독립 앱과 SDK는 빠른 도입에 적합하지만, 사용자는 QR이나 딥링크를 거치며 화면을 전환해야 합니다. GIWA Wallet에 네이티브하게 통합하면 사용자가 익숙한 승인 화면에서 dApp의 요청 범위를 확인하고 곧바로 증명할 수 있습니다. 원본 Dojang 데이터는 지갑 밖으로 내보내지 않으면서도 피싱성 요청과 불필요한 이탈을 줄이는 가장 자연스러운 UX가 됩니다.

03 / SCOPE

PoC와 공식 Dojang 데이터 연동의 구분

현재 PoC는 Dojang 발급 이후의 ZK 증명 파이프라인을 검증합니다. 공식 Verified Address는 사용자의 KYC와 업비트의 발급 절차를 거쳐 생성되는 운영 데이터입니다. PoC에서는 팀이 배포한 테스트 attester로 mock EAS 데이터를 등록하고, attestation 확인부터 기기 내 proof 생성, GIWA verifier 검증까지 구현했습니다. Production 단계에서는 발급자 주소, schema와 정책을 공식 Dojang 데이터에 맞춰 연결합니다.
