IMPLEMENTATION

Dojang 데이터에서
GIWA 검증까지

Dojang이 발급한 자격 데이터를 ZKProofport 회로가 검증합니다. 사용자는 원본 지갑과 attestation을 공개하지 않고 proof를 만들며, GIWA verifier는 그 proof만 확인합니다. 현재 PoC에서는 발급 단계에 테스트 attester를 사용합니다.

01 / FLOW

Dojang → ZKProofport → GIWA

TRUST DATA Dojang attestation
→
PRIVATE CHECK ZKProofport circuit
→
USER DEVICE Mobile prover
→
ONCHAIN VERIFY GIWA HonkVerifier
  1. 01Dojang이 Verified Address나 Balance 같은 자격 데이터를 발급합니다.
  2. 02ZKProofport 회로가 attestation, 발급자와 지갑 소유권을 private input으로 확인합니다.
  3. 03모바일 기기에서 조건 충족 여부만 담은 ZK proof를 생성합니다.
  4. 04GIWA verifier가 원본 Dojang 데이터 없이 proof의 유효성을 검증합니다.

04 / DOJANG

공식 Dojang 연동 지점

PoC에서 검증한 범위는 발급 이후의 ZK 증명 파이프라인입니다. 공식 Dojang 연동에서는 테스트 attester를 운영 발급 데이터로 바꾸고, 실제 발급자 주소, schema와 정책을 회로의 검증 규칙에 반영합니다. 이후 모바일 prover와 GIWA verifier 구조는 같은 역할을 이어갑니다.
