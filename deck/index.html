01 / PROBLEM

검증 결과만 받고,
원본 개인정보는 수집하지 않습니다.

DIRECT CHECK

서비스가 직접 확인하면

인증 지갑, 인증 상태, 앱 사용 기록이 하나의 공개된 지갑 그래프에 연결됩니다. 서비스가 관리해야 할 민감정보도 늘어납니다.

PRIVATE PROOF

증명만 확인하면

서비스는 조건이 참인지 확인하되 원본 지갑 주소와 인증 데이터를 받지 않습니다. 사용자는 필요한 사실만 선택해 증명합니다.
